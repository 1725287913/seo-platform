## 快速开始

### 1. 准备环境

需要 **Python 3.10+**。下载项目后，进入目录装依赖：

```bash
cd seo-platform/backend
pip install -r requirements.txt
```

### 2. 配置密钥

复制配置模板，改名为 `.env`，填入你自己的密钥（**`.env` 不会上传到 Git，只有你自己能看到**）：

```bash
# Windows
copy .env.example .env

# Mac / Linux
cp .env.example .env
```

然后编辑 `.env`：

```ini
DEEPSEEK_API_KEY=sk-你自己的key
DEEPSEEK_MODEL=deepseek-flash
```

> 密钥去哪申请？看 `.env.example` 里每一行的注释，都写好了申请地址。
> 也可以启动后在界面的「API 密钥」页点选服务商，自动帮你写好。

### 3. 启动

```bash
cd seo-platform/backend
python -m uvicorn main:app --port 8020
```

浏览器打开 **http://localhost:8020**

> ⚠️ **这个链接不能凭空点开**，两点要记牢：
> 1. 必须先在上面那个终端窗口里把 `uvicorn` 命令跑起来（窗口不关、不报错），端口上才有服务；命令没跑或已经关掉，浏览器只会显示「无法访问此网站 / ERR_CONNECTION_REFUSED」。
> 2. `localhost` 的意思是"**打开链接的这台电脑自己**"。所以这个链接只对**你自己本机**有效——别人拿到仓库，点它打开的是他自己电脑的 8020 端口，永远打不开。让别人用，要么他也在自己电脑上跑一遍上面两条命令，要么用部署到服务器的在线版。

## 关于密钥安全

本项目遵循**密钥与代码分离**：

- `.env.example` 只放变量名 → 进仓库
- `.env` 放真实密钥 → 被 `.gitignore` 排除，**永不进仓库**
- 代码里没有任何硬编码密钥
- 后端返回给前端的配置会自动脱敏（`sk-abc…`），前端拿不到完整密钥
- `backend/data/` 里的运行时数据（你的文章、推送记录）同样不进仓库

也就是说：**别人拿到这个项目，必须自己配自己的密钥才能用。**

## 常见问题

**Q：启动后页面能打开，但生成文章报错？**
A：多半是没配密钥。打开「API 密钥」页看顶部有没有红条提示，或检查 `.env` 里 `DEEPSEEK_API_KEY` 是否已填。

**Q：百度推送返回 `token invalid`？**
A：站点域名或 token 还是占位值。到「站点配置」页点「百度跑通体检」，它会逐项告诉你缺什么。

**Q：想要别人也能打开这个平台？**
A：**直接把在线预览链接发给他** —— <https://seo-matrix-platform.app.workbuddy.host/>，点开就能用，不用装任何东西。

**Q：那为什么不能直接给朋友发 `http://localhost:8020`？**
A：因为 `localhost` 指的是"打开链接的这台电脑自己"。朋友点它，打开的是他自己电脑的 8020 端口，而他那台电脑上并没有跑这个服务，所以一定打不开。要给别人用，必须是公网地址（就是上面那个在线版），或者在对方电脑上也跑一遍「快速开始」的两条命令。

**Q：还有别的给别人的方式吗？**
A：① 私有仓库邀请对方为协作者（对方只能看代码，看不到运行效果）；② 部署到自己的服务器／云主机（有公网 IP 或域名，对方点链接即用）。
